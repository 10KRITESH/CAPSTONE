# Project State: Byzantine-Robust FL-IDS

## 1. Project Overview
A Byzantine-robust federated-learning intrusion detection system (FL-IDS) evaluated on CICIoT2023 (8 classes, 10 clients, Dirichlet alpha=0.5).
Combines per-class reputation tracking, decoupled body/head aggregation, and a 3-tier security state machine (Trusted/Probation/Quarantined).
Features a tamper-evident audit layer logging all security state transitions to SQLite and simulated JSON ledger.

## 4. Key Verified Findings & Pointers
- **Step 1 Comparability:** Replicated Phase E4 Legacy D0 honest quarantine (21.67% on CPU loop) vs 63.33%–77.08% on GPU resident loop. CPU batch-shuffling noise partially masked minority-class probe drops; deterministic GPU residency exposed them. Fixed defense maintains 6.25%–8.33% honest quarantine across both loops ([`FINDINGS_ADDENDUM.md` E8.2](file:///home/kriteshgoud/Documents/NMIMS/projects/CAPSTONE/FINDINGS_ADDENDUM.md#e82-step-1-comparability--environment-isolation-96-simulations)).
- **Step 2 Ablations:** Warmup suppression (prevents early false alarms) and head salience (preserves RECON F1 by +1.48%) proven necessary; cohort cosine is uninformative against targeted label flips ([`FINDINGS_ADDENDUM.md` E8.3](file:///home/kriteshgoud/Documents/NMIMS/projects/CAPSTONE/FINDINGS_ADDENDUM.md#e83-step-2-leave-one-out-feature-ablation-matrix-96-simulations)).
- **Step 3 Baselines:** Coordinate Median is remarkably robust (47.59% Macro-F1, 42.61% RECON F1, 13.40% ASR); Proposed Fixed defense cuts D0 honest quarantine from 77.08% to 6.25% and recovers RECON F1 to 21.93% (vs 1.26% FedAvg) with 50% attacker detection ([`FINDINGS_ADDENDUM.md` E8.4](file:///home/kriteshgoud/Documents/NMIMS/projects/CAPSTONE/FINDINGS_ADDENDUM.md#e84-step-3-classical-byzantine-robust-baseline-comparisons-108-simulations)).
- **Step 6 Latency Tolerance:** Attackers can be contained as late as round $T=10$ or $T=20$ and the global model fully recovers representation (43.65% RECON F1), proving immediate round-1 exclusion is not required ([`FINDINGS_ADDENDUM.md` E8.6](file:///home/kriteshgoud/Documents/NMIMS/projects/CAPSTONE/FINDINGS_ADDENDUM.md#e86-step-6-oracle-delay-tolerance-60-simulations)).
